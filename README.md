## Installation

### Using npm(ES6 module):
```alias

npm i w-package-tools-e2e

import rollupCode from 'w-package-tools-e2e/src/rollupCode.mjs'
rollupCode({...})

import rollupWorker from 'w-package-tools-e2e/src/rollupWorker.mjs'
rollupWorker({...})

```
