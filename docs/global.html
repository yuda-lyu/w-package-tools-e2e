(async) waitUntilExist(page, label, fn, optopt) → {Promise}

Description:

  • 偵測驅動之等待：每步驟先偵測對象存在或就緒再進下一步，逾時即拋錯(代表真實異常，而非固定等待不夠)

    fn於瀏覽器端執行，跨行程序列化故不可使用閉包變數，傳值一律經opt.arg。 fn為async函數(例如頁面內fetch後端再判斷)時改為逐次page.evaluate並await其結果輪詢：Playwright之waitForFunction同步呼叫predicate， async函數回傳之Promise為truthy而第一次即放行(不重試、逾時無效，條件不成立也照樣通過；2026-09-28查得共20處： w-web-sso之ag-grid等待以async判斷直呼waitForFunction 14處、w-web-task以async判斷呼叫waitUntilExist 6處)
